# index-knowledge

Generates AGENTS.md by indexing markdown content under docs and optionally writes Copilot instructions.

## Usage

```text
usage: index-knowledge [-h] [--copilot]

Index knowledge files and generate AGENTS.md

options:
  -h, --help  show this help message and exit
  --copilot   Create .github/copilot-instructions.md file
```

## Example

```bash
index-knowledge --copilot
```
