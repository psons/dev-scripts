# Spec Mechanics with DDF and Skills
DDF should be used as a format where an AI skill uses a template to produce output that fits in an SDLC or BIT Velocity step.   The DDF template can be used to leave attributes for a script to process as a doen stream step of AI.

A rich set of templates should be provided to assure AI output is organized in a digestible DRY way do that human review can be efficient and have repeatable expectations for where things are.

With templated documents for AI skills,   
 - software modules specs can be more consistent, so humans can isolate updates to one part of a spec without causing internal inconsistencies.
 - various steps of the BIT Velocity Stages that complement each other and encourage the DRY principle, both internally to spec documents and externally to provide context for each piece.
